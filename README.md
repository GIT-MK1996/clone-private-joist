# Werkbon

Offertes en facturen voor Nederlandse vakmensen. Offerte maken op je telefoon, klant zegt online akkoord, met één tik een factuur.

- `web/` – de app (Next.js, TypeScript, Tailwind, Drizzle + libSQL)
- `replica/` – recon, features en architectuur

## Lokaal starten

```bash
cd web
npm install
npm run dev
```

Open http://localhost:3000/app. De database (`web/local.db`) wordt bij de eerste start aangemaakt met een voorbeeldbedrijf.
